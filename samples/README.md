# Sample scans

Put sample sheets here. Everything in this folder except this README is
git-ignored, because sheet music is often copyrighted and this repository
is public.

Layout:

```
samples/
  raw/            # the scans as you have them: .pdf, .png, .jpg, .tif
  truth/          # optional: hand-corrected .musicxml with the same base name
```

For each sample, a short note in the file name helps, e.g.
`raw/adon-olam_SATB-separate_phone-photo.jpg` or
`raw/erev-shel-shoshanim_SA-shared-staff_photocopy.pdf`.

Useful variety: separate staff per voice, two voices sharing one staff,
Hebrew lyrics, English lyrics, mixed, several verses, phone photos,
photocopies, low-resolution scans.
